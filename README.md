# 🌪️ CycloneShield AI

## Cyclone Impact & Infrastructure Vulnerability Forecaster

CycloneShield AI is a machine learning-based web application that estimates infrastructure vulnerability during cyclone conditions.

The system analyzes cyclone-related and infrastructure-related parameters and predicts the risk level as:

- LOW RISK
- MEDIUM RISK
- HIGH RISK

## 🚀 Features

- Cyclone vulnerability prediction
- Random Forest machine learning model
- Live weather data enrichment
- Risk confidence percentage
- Risk factors explanation
- Recommended safety actions
- Dynamic vulnerability map prototype
- Simple and interactive web dashboard

## 📊 Input Parameters

The model uses the following inputs:

- Wind speed
- Rainfall
- Distance from coastline
- Infrastructure age
- Population density
- Cyclone intensity

## 🛠️ Technologies Used

- Python
- Flask
- Scikit-learn
- Random Forest
- Pandas
- HTML
- CSS
- JavaScript
- Open-Meteo Weather API
